## File structure
```
index.html  about.html  news.html  gallery.html  404.html
css/style.css            one organised stylesheet (tokens → base → layout → components → pages)
js/config.js             school contact data (single source for header/footer/contact/map)
js/i18n.js               UI strings (uz, en) + tiny i18n engine (data-i18n attributes)
js/main.js               header/footer templates, language switch, menu, reveal, count-up, image fallback
js/news.js               news list, filter, load-more, detail view, home "latest news"
js/gallery.js            gallery grid, filter chips, home mosaic preview
js/lightbox.js           accessible lightbox (keyboard, swipe, focus trap)
data/news.json           news items (uz/en)
data/gallery.json        gallery items (uz/en captions, category, featured)
images/                  original photos (never renamed/deleted)
images/optimized/        generated by tools/optimize_images.py (≤1600px, JPEG + WebP, q80)
assets/                  logo.svg, favicon.svg, ornament-pattern.svg, divider.svg
tools/optimize_images.py Pillow script for optimized copies
sitemap.xml robots.txt README.md
```

## Design tokens
| token | value | use |
|---|---|---|
| navy-900 | #0B1F3A | primary, hero, footer |
| navy-700 | #1C3A63 | hover, secondary surfaces |
| gold-500 | #C9A24B | accents on navy only (decorative) |
| gold-700 | #7D5F1C | gold-toned text on light backgrounds (AA) |
| cream | #FAF7F0 | page background |
| mist | #E8EDF3 | soft blue-grey surfaces |
| teal | #0F766E | the one vivid accent: badges, hover, focus |
| ink | #1B2433 / muted #4A5568 | body text |
- Fonts: Playfair Display (headings), Inter (body) via Google Fonts, `display=swap`.
- Radius 14px, soft layered shadows, 8px spacing scale, fluid type with `clamp()`.
- Motif: 8-point star lattice (girih/ikat inspired) at 4–8% opacity, gold ornamental dividers.

## Bilingual system
- Short UI strings: `data-i18n="key"` / `data-i18n-attr="aria-label:key"` resolved from `js/i18n.js`.
- Long prose (About page, director's welcome): paired blocks `data-lang="uz"` / `data-lang="en"`
  shown/hidden by CSS from `<html lang>` — content stays in HTML (good for SEO, no JS size cost).
- Data: `*_uz` / `*_en` fields. A third language (ru) = add a dictionary + `*_ru` fields + one CSS rule.
